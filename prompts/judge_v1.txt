- uncertain: evidence is insufficient to choose acceptable versus incorrect.

Check these boolean gates:

Then assign four integer rubric scores, considering all three intended distractors

plausibility (0–2): Would B1–B2 learners plausibly confuse the distractors with the

do not require all options to be grammatical. For example, "depend on/in/at/for"
can test a preposition, while unrelated malformed spellings can be irrelevant cues.

distinctness (0–2): 0 = duplicate or effectively repeated distractors with no useful
contrast. 1 = partially redundant distractors. 2 = three meaningfully distinct
confusions that each test the same learning point from a different plausible angle.

no_cues (0–2): 0 = a strong irrelevant length, formatting, spelling, or grammatical
cue reveals the answer without the target knowledge. 1 = a weak incidental cue.
2 = comparable presentation with no irrelevant shortcut. Differences in grammar
are legitimate when grammar is the target; do not penalize that difference alone.
